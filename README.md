# Marilyn's Banana Bread

A website for homemade banana bread baked by Marilyn. The site introduces her small business, shows the available banana bread flavors, shares storage tips, and makes ordering simple and easy.

## About

This project is a single-page bakery website designed to make homemade banana bread feel personal, inviting, and easy to order. It includes a focused presentation of the brand, products, and ordering information.

View the live site [here](https://tinyurl.com/k65pzuff).

## Features

- Responsive layout for desktop and mobile screens
- Hero section with the bakery's message and call to action
- Menu section for highlighting available banana bread options
- About section that shares the bakery story
- Storage guidance for keeping banana bread fresh
- Step-by-step ordering information

## Why I Built It

I built this website to support my mom as she starts her home business selling homemade banana bread. I wanted to create a simple and welcoming online space where customers can see her different banana bread options, learn more about them, and easily place an order.

## Tech Stack

- [Next.js](https://nextjs.org/) 16 with the App Router
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/) for animations
- [Lucide React](https://lucide.dev/) for icons
- [next-themes](https://github.com/pacocoursey/next-themes) for theme switching

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
